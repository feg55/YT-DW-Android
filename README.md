# YT-DW Android

Android-приложение для анализа ссылок и сохранения аудио/видео через `yt-dlp` и FFmpeg.

## Возможности

- анализ одиночных ссылок и плейлистов;
- предварительный просмотр и редактирование метаданных;
- загрузка аудио M4A и видео MP4;
- обложки, названия, исполнитель, альбом и номера треков;
- сохранение через Android MediaStore без запроса доступа ко всему хранилищу;
- фоновая очередь, пауза, отмена и повтор ошибок;
- русский и английский интерфейс.

Минимальная версия — Android 10 (API 29).

## Сборка

Требуются JDK 17 и Android SDK с платформой API 37. Gradle Wrapper загружает закреплённую версию `yt-dlp` и проверяет её SHA-256.

Windows:

```powershell
.\gradlew.bat check assembleDebug
```

Linux/macOS:

```bash
chmod +x gradlew
./gradlew check assembleDebug
```

Debug APK появится в `app/build/outputs/apk/debug/`.

## Release-подпись

Без дополнительной настройки локальный release подписывается debug-ключом и предназначен только для тестирования.

Для публикации:

1. Создайте постоянный keystore.
2. Скопируйте `keystore.properties.example` в `keystore.properties`.
3. Заполните путь, alias и пароли.
4. Выполните `./gradlew assembleRelease`.

Не добавляйте `keystore.properties` и keystore в Git. Потеря ключа лишит возможности выпускать совместимые обновления.

## Разрешения и данные

Приложение использует интернет и foreground service для активных загрузок. Разрешение на уведомления запрашивается только при запуске очереди на Android 13+. Доступ ко всему хранилищу не требуется. Собственный сервер и сбор аналитики отсутствуют.

## Ограничения

Сайты могут менять защиту и форматы без предупреждения. Для YouTube используется совместимый embedded-клиент с резервным стандартным запросом. Проект не связан с YouTube или другими поддерживаемыми сервисами. Пользователь отвечает за соблюдение правил сервисов и авторских прав.
